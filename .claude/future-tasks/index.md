# Future tasks (archive)

Until 2026-11-20 SSSB's backlog was a file per task in this directory. **The backlog is now this repository's GitHub
issues**, ranked on the [SSSB backlog Project](https://github.com/orgs/safeinsights/projects/6); `CLAUDE.md` ("The backlog is this repository's GitHub issues")
has the rules for filing one. Add nothing here.

What stays is a frozen record:

- `resolved/` holds the tasks finished before the move, each with its implementation summary, listed below. It is
  exempt from the doc-path gate (`tests/docs/doc-set.ts`), like the other dated records, because the work that
  resolved a task routinely moved what it cites.
- `issue-map.json` maps every task file that was open at the move to the issues it became (a bundle of independent
  items became several), or to the reason it was not filed. Each issue links back to its file at the commit it was
  migrated from.

Every open task was re-verified against the tree when it moved: work found already done was dropped from its issue,
drifted numbers were re-measured, and adopter specifics were generalised, since issues are public.
